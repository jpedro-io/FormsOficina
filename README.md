# Workspace Integrado
Formulário de inscrição e avaliação da oficina Workspace Integrado: Organizando Projetos e Alinhando Negócios com o Notion. O projeto foi desenvolvido no contexto da disciplina Organização, Sistemas e Métodos, por estudantes de Sistemas de Informação do IFBA para estudantes da UESB.

## Funcionalidades
Formulário responsivo para computador e celular.
Coleta de nome, e-mail, CPF, celular e avaliação da oficina.
Validação dos dados no navegador e novamente na API.
Verificação do CPF e limite de uma resposta por CPF.
Gravação das inscrições em PostgreSQL no Neon.
Limite de tentativas e mensagens de erro sem expor detalhes internos.

## Tecnologias
HTML, CSS e JavaScript no front-end.
TypeScript nas rotas da API.
PostgreSQL no Neon.
Vercel para publicação e execução das rotas serverless.
